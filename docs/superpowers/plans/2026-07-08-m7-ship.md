- snap-set keys and defaults (exact): `ports.https`=8971 (1024–65535), `tls.enabled`=true (true|false), `tls.cert-profile`=rsa-4096 (rsa-4096|ecdsa-p256), `certsync.interval`=60 (integer 10–3600), `detector`=unset→auto-detect (`/dev/dri/renderD*` present → ov, else cpu; explicit ov|coral|cpu overrides; render-time only).

```sh
# snapctl get with default: snap options are unset until the user sets them.
cfg_get() { v="$(snapctl get "$1" 2>/dev/null)"; [ -n "$v" ] && printf '%s' "$v" || printf '%s' "$2"; }
```

- [ ] **Step 2: `listen.conf.in`** — copy the current `listen.conf` content, with the external block parameterized:

```
listen 127.0.0.1:5000;
# __TLS_BLOCK__ replaced at render: TLS form (default) or plain-HTTP form (tls.enabled=false)
```

`nginx-run` renders it before nginx starts (EVERY start — this is service config, not `config.yml`):
- TLS form: `listen __HTTPS_PORT__ ssl;` + `http2 on;` + the existing ssl_* lines + HSTS (byte-identical to today's block, port token swapped).
- Plain form (tls.enabled=false): `listen __HTTPS_PORT__;` only (no ssl_* lines, no HSTS).
Implementation: two heredoc blocks in `nginx-run` selected by `TLS=$(cfg_get tls.enabled true)`; `PORT=$(cfg_get ports.https 8971)`; write `$SNAP_DATA/nginx/conf/listen.conf`; adjust the nginx.conf include path if it pointed at the static file.

- [ ] **Step 3: cert-profile.** In `nginx-run` generation block: `PROFILE=$(cfg_get tls.cert-profile rsa-4096)`; `rsa-4096` keeps the existing command byte-identical; `ecdsa-p256` uses `openssl req -new -x509 -nodes -newkey ec -pkeyopt ec_paramgen_curve:P-256 -days 365 -subj "/O=FRIGATE DEFAULT CERT/CN=*" -keyout privkey.pem -out fullchain.pem` (same umask/paths).
- [ ] **Step 4: certsync interval.** `certsync-run`: `INTERVAL=$(cfg_get certsync.interval 60)`; replace both hard-coded `sleep 60` loop points; the s_client connect target port becomes `$(cfg_get ports.https 8971)`.
- [ ] **Step 5: detector render.** In `spike/config/frigate-config.yml`, wrap the existing `ov` detectors+model region in `# DETECTOR-OV-BEGIN`/`# DETECTOR-OV-END` markers and ADD marker-wrapped CPU and CORAL blocks (CPU: `type: cpu`, model path `/opt/frigate/models/cpu/cpu_model.tflite`, labelmap `/opt/frigate/models/labelmap.txt`, 320×320 nhwc rgb ssd; CORAL: the M6 phase block verbatim). In `frigate-run` AND `validate-config` render paths: `DET=$(cfg_get detector "")`; if empty: `ls /dev/dri/renderD* >/dev/null 2>&1 && DET=ov || DET=cpu`; render keeps ONLY the chosen block's contents (strip its markers) and deletes the other two marker regions (sed range deletes, LIVECAM idiom). Render-once guard unchanged.
- [ ] **Step 6: `configure` hook** (`spike/snap/hooks/configure`, POSIX sh):

```sh
#!/bin/sh
# Validate snap-set keys, then restart affected services. NEVER touches config.yml
# (render-once: operator-owned after first boot; detector applies at next render only).
set -e
fail() { echo "configure: $1" >&2; exit 1; }
P=$(snapctl get ports.https);      [ -z "$P" ] || { case "$P" in *[!0-9]*) fail "ports.https must be an integer";; esac
                                     [ "$P" -ge 1024 ] && [ "$P" -le 65535 ] || fail "ports.https out of range 1024-65535"; }
T=$(snapctl get tls.enabled);      [ -z "$T" ] || [ "$T" = true ] || [ "$T" = false ] || fail "tls.enabled must be true|false"
C=$(snapctl get tls.cert-profile); [ -z "$C" ] || [ "$C" = rsa-4096 ] || [ "$C" = ecdsa-p256 ] || fail "tls.cert-profile must be rsa-4096|ecdsa-p256"
I=$(snapctl get certsync.interval);[ -z "$I" ] || { case "$I" in *[!0-9]*) fail "certsync.interval must be an integer";; esac
                                     [ "$I" -ge 10 ] && [ "$I" -le 3600 ] || fail "certsync.interval out of range 10-3600"; }
D=$(snapctl get detector);         [ -z "$D" ] || [ "$D" = ov ] || [ "$D" = coral ] || [ "$D" = cpu ] || fail "detector must be ov|coral|cpu"
snapctl restart frigate.nginx frigate.certsync 2>/dev/null || true
```

(Restart scope: nginx+certsync consume keys live; frigate is deliberately NOT restarted — detector is render-time only. Adapt the restart-line form to what `snapctl restart` accepts, verified live.)
